К установке обязательны библиотеки:
pip install selenium
pip install webdriver-manager
pip install pandas
webdriver-manager  отвечает за автоматическое скачивание драувера для управления браузерами

Чтоб развернуть в кубере скрипт могу переписать на Selenium Grid и CronJob.
Это единственный верный способ развернуть селениум в кубере.

На выходе объедененный датафрейм из 3 источников готовый к любому виду отправки(email, S3, merge в таблицу, запись в Excel)
